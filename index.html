1거래 내역 불러오기

거래소에서 받은 CSV를 고릅니다(여러 개 한꺼번에 가능). 업비트·빗썸·코인원에서 내려받은 전체 내역 파일을 그대로 넣으면 됩니다. 파일은 브라우저 메모리에서만 읽고, 어디에도 업로드하지 않습니다.

🔗 업비트 API로 바로 불러오기 (조회 전용 키)

업비트 → 마이페이지 → Open API 관리에서 자산조회 · 주문조회 · 입출금조회만 체크해 키를 만드세요. 주문하기 · 출금하기는 체크하지 마세요. 발급할 때 이 PC의 IP 주소를 등록해야 합니다. 키는 이 화면 메모리에만 있고 어디에도 저장하지 않습니다.
이 기능은 업비트 서버에 내 거래 내역을 받아오는 요청만 보냅니다(분석·증명서는 그대로 내 PC 안에서). 받아온 뒤에는 인터넷을 끊어도 됩니다.

2거래 분류

입출금 짝 맞추기, 에어드롭·스테이킹 구분, 출처가 애매한 거래를 표시합니다. 노란 줄은 본인 확인이 필요한 거래이며, 분류를 바꾸면 세액이 바로 다시 계산됩니다.

3손익과 예상 세액

국내 거래소는 이동평균법, 해외 거래소·개인 지갑은 선입선출법으로 취득가를 계산합니다. 기본공제 250만 원, 세율 22%(지방세 포함) 기준입니다.

4증명서 발급과 체인 기록

제출용 요약 증명서에는 합계만 들어갑니다. 거래 하나하나는 상세 내역 파일에 담아 본인이 보관합니다. 체인에는 요약 증명서의 지문(해시)만 기록합니다.

🔒 영지식 범위 증명서 금액은 숨기고 "기준 이하"만 증명

손익 금액 대신 잠긴 상자(커밋먼트)와 수학적 증명만 넣습니다. 받는 사람은 실제 금액을 모른 채 "손익 ≤ 기준 금액"이 참인지만 확인합니다. 거짓 주장(기준 초과)은 증명 자체가 만들어지지 않습니다.

제출받은 증명서 검증

은행·세무사·임대인 입장입니다. 받은 파일을 넣으면 내용의 지문을 다시 계산해 체인 기록과 대조합니다. 원본 거래 내역 없이도 "발급 당시 그대로인지"를 확인할 수 있습니다.

체인 기록

데모 체인은 이 브라우저 안의 간이 블록체인입니다(블록마다 앞 블록의 해시를 이어 붙임). 실제 시연에서는 Sepolia 테스트넷 거래 링크로 같은 내용을 보여 줄 수 있습니다. 어느 쪽이든 거래 내역은 올라가지 않고 64자리 지문만 남습니다.
