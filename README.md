# CoinProof · 내 코인 내역 증명서

Nesa AI × Blockchain Valley 해커톤 (Track 1 Private Input + Track 3 Verifiable AI) 시연 앱.

> 거래 내역은 내 PC 밖으로 나가지 않는다. 합계만 담은 증명서를 만들고, 그 지문(해시)만 블록체인에 남긴다.

## 실행
1. Node.js가 깔린 노트북에서 `시연앱_실행.cmd` 더블클릭 → 브라우저에 `http://localhost:5177`이 열림
2. Node가 없으면 `index.html`을 크롬으로 바로 열어도 동작함 (Sepolia 기록만 안 됨)
3. 인터넷이 없어도 모든 기능이 동작함 (외부 라이브러리·CDN 없음)

## 시연 순서 (약 4분)
1. **① 탭 → 샘플 내역 불러오기**: 18건이 분류됨. 상단 "외부로 나간 요청 0건" 강조
   - 업비트 출금 ↔ 바이낸스 입금 자동 짝 맞추기 (과세 아님)
   - 에어드롭·스테이킹 구분, 개인 지갑 이체 판별
   - 노란 줄 = 출처 미상 XRP 500개 → 취득가 0원으로 잡혀 세금이 커짐
2. 노란 줄 분류를 **"외부 보유분 이전 (시가)"** 로 바꾸기 → 예상 세액 770,214원 → 477,928원으로 즉시 재계산
3. **증명서 만들기** → 합계만 있고 지갑 주소·잔고·개별 거래는 없음을 보여 줌
4. **데모 체인에 기록** → 지문 64자리만 올라감 (③ 탭에서 블록 확인)
5. **② 탭 → 방금 발급한 증명서 불러오기** → ✅ 발급 당시 그대로
6. **위조 시연: 손익을 낮춰 보기** → ❌ 체인 기록과 다릅니다
7. (선택) 상세 내역 .json을 넣으면 거래 18건 묶음 지문(머클 루트)까지 일치 확인

## 영지식 범위 증명 (기본 버전)
① 탭 맨 아래 "🔒 영지식 범위 증명서". 손익 금액을 Pedersen 커밋먼트로 잠그고 "양도손익 ≤ 기준 금액"만 증명.
- 방식: x = 기준 − 손익 을 32비트로 분해, 비트마다 0/1 OR 증명(CDS Σ-프로토콜) + Fiat–Shamir, Π C_i^(2^i) = g^T·C^(−1) 로 연결
- 그룹: RFC 3526 2048-bit MODP, g = 4, h = 해시에서 유도(이산로그 관계 모름)
- 증명 약 1~2초, 검증 약 3초, 증명 크기 약 53KB, 외부 라이브러리·인터넷 불필요
- 거짓 주장(실제 손익 > 기준)은 증명이 만들어지지 않음. 기준 금액·주장 문구·증명 값 중 하나만 바뀌어도 검증 실패
- 한계: 손익이 거래 내역에서 올바르게 계산됐다는 증명(계산 무결성)은 아직 아님 → 다음 단계(zk-SNARK)

## 실제 거래소 데이터
### 파일로 (인터넷 불필요)
"CSV 파일 선택"에서 여러 파일을 한꺼번에 고르면 합쳐서 분석합니다. 거래소에서 내려받은 원본 형식을 그대로 읽습니다.

| 거래소 | 파일 | 읽는 것 |
|---|---|---|
| 업비트 | 전체 내역 (`event_at,event_type,…`) | 매수·매도(BTC 마켓은 원화 환산), 코인 입출금, 내부 이체·토큰 전환 |
| 빗썸 | 전체 내역 (`거래일시,자산,결제통화,거래구분,…`) | 매수·매도(원화/코인 수수료 자동 구분), 입출금(주소 포함), 스테이킹, 이벤트·에어드랍 |
| 코인원 | 체결 내역 + 입출금 내역 | 매수·매도, 입출금, 스테이킹 보상(당시 가격), 이벤트 리워드 |

- 원화 입출금·이자, 렌딩·대여처럼 손익과 무관한 줄은 제외하고 몇 건 뺐는지 표시
- 여러 해 내역이면 **세금 계산 대상 연도**를 고름. 취득가는 이전 연도까지 모두 반영
- 거래소 간 출금→입금(24시간 안, 수량 차이 2% 이내)은 본인 이체로 자동 짝지음
- 보유량보다 0.1% 미만 더 판 것은 수수료·반올림 차이로 보고, 그 이상만 "확인 필요"
- 개인 거래 내역은 `_private/` 폴더에 두면 GitHub에 올라가지 않음 (`.gitignore`)

### 업비트 API로 (조회 전용)
"🔗 업비트 API로 바로 불러오기"에 Access/Secret Key를 넣고 "거래 내역 받아오기".
- 키는 업비트 → 마이페이지 → Open API 관리에서 **자산조회·주문조회·입출금조회만** 체크 (주문·출금 권한 금지), 이 PC의 IP 등록 필요
- 브라우저는 업비트에 직접 요청할 수 없어 `server.js`가 서명(JWT HS256 + SHA512 쿼리 해시)해 대신 요청. 키는 저장·기록하지 않음
- 서버는 조회 경로 5개(`/v1/accounts`, `/v1/orders/closed`, `/v1/order`, `/v1/deposits`, `/v1/withdraws`)만 허용하고, 이 앱 화면에서 온 요청만 받음
- 주문은 업비트 제한(1회 7일 범위)에 맞춰 주 단위로 받아 합치고, 경계 중복은 주문 ID로 제거
- 화면 위 표시에 업비트 조회 건수를 따로 보여 줌 (분석·증명서는 그대로 내 PC 안에서)
- 시연앱_실행.cmd(로컬 서버)로 열었을 때만 동작
