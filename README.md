# CoinProof · 내 코인 내역 증명서

Nesa AI × Blockchain Valley 해커톤 (Track 1 Private Input + Track 3 Verifiable AI) 시연 앱.

> 거래 내역은 내 PC 밖으로 나가지 않는다. 합계만 담은 증명서를 만들고, 그 지문(해시)만 블록체인에 남긴다.

## 실행
1. Node.js가 깔린 노트북에서 `시연앱_실행.cmd` 더블클릭 → 브라우저에 `http://localhost:5177`이 열림
2. Node가 없으면 `index.html`을 크롬으로 바로 열어도 동작함 (Sepolia 기록만 안 됨)
3. 인터넷이 없어도 모든 기능이 동작함 (외부 라이브러리·CDN 없음)

## 시연 순서 (약 4분)
1. **① 탭 → 샘플 내역 불러오기**: 18건이 분류됨. 상단 "외부로 나간 요청 0건" 강조
   - 업비트 출금 ↔ 바이낸스 입금 자동 짝 맞추기 (과세 아님)
   - 에어드롭·스테이킹 구분, 개인 지갑 이체 판별
   - 노란 줄 = 출처 미상 XRP 500개 → 취득가 0원으로 잡혀 세금이 커짐
2. 노란 줄 분류를 **"외부 보유분 이전 (시가)"** 로 바꾸기 → 예상 세액 770,214원 → 477,928원으로 즉시 재계산
3. **증명서 만들기** → 합계만 있고 지갑 주소·잔고·개별 거래는 없음을 보여 줌
4. **데모 체인에 기록** → 지문 64자리만 올라감 (③ 탭에서 블록 확인)
5. **② 탭 → 방금 발급한 증명서 불러오기** → ✅ 발급 당시 그대로
6. **위조 시연: 손익을 낮춰 보기** → ❌ 체인 기록과 다릅니다
7. (선택) 상세 내역 .json을 넣으면 거래 18건 묶음 지문(머클 루트)까지 일치 확인

## 구조
| 부분 | 내용 |
|---|---|
| `index.html` | 앱 전체 (분류 엔진, 세액 계산, SHA-256, 머클 루트, 데모 체인, 검증) |

## 계산 규칙 (시연용 단순화)
- 국내 거래소: 이동평균법 / 해외 거래소·개인 지갑: 선입선출법
- 기본공제 250만 원, 세율 22% (지방세 포함)
- 에어드롭·출처 미상 입금: 취득가 0원 (보수적), 스테이킹 보상: 받은 날 시가
- 본인 계정 간 이체: 과세 아님, 취득가 그대로 이전
- 가상자산 과세는 2029년 1월로 유예 추진 중. 지침 확정 시 규칙 갱신 필요
